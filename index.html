Session

Background mode — keep running while you use other apps

Publishes a silent media stream so Android treats the tab as foreground playback and stops throttling it. A notification appears in the shade: Pause = Stop. Keep the Chrome tab open (switching apps is fine, swiping Chrome away is not) and exclude Chrome from battery optimisation. The game itself needs the screen on to be playable.

Intiface (buttplug.js) — optional test transport Not connected

Direct Web Bluetooth is the default and needs nothing here. To test through Intiface instead: start Intiface Central (Engine running, Listen on all network interfaces + Bluetooth LE on), connect below, scan, then switch a device card's Transport to Intiface and pick the toy.

Log

Connection order matters. Press Connect first (opens the scanner), then power the Lovense toy on. The reverse order scans fine but times out after ~30s.
Satisfyer: if it was ever paired with the Satisfyer Connect app or Android Bluetooth settings, Forget it in system settings, then hold the button 15s (reset pairing) and 4s (discoverable) before connecting.
